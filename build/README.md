# Build Assets

## icon.ico

Place your application icon here (256x256 or 512x512 recommended).

**How to create:**
1. Go to https://convertio.co/png-ico/
2. Upload your eye logo (PNG/JPG/SVG)
3. Convert to .ico format
4. Save as `icon.ico` in this folder

**Free icon resources:**
- https://icon-icons.com/icon/eye/134021
- https://www.flaticon.com/free-icon/eye_159604
- https://fontawesome.com/icons/eye

The icon will be used for:
- Application icon (taskbar, window)
- Desktop shortcut
- Start menu shortcut
- Installer icon
- Uninstaller icon
