# Assets Folder

## Required Files

### Logo (logo.png)
- **Path:** `assets/logo.png`
- **Purpose:** Displayed under "SKRYI" heading in the app
- **Requirements:**
  - Format: PNG with transparency
  - Size: 150x150px (will be scaled automatically)
  - Design: Eye icon or SKRYI branding

### Icon (icon.ico) - For Build Only
- **Path:** `build/icon.ico`
- **Purpose:** Windows installer icon
- **Requirements:**
  - Format: .ico
  - Sizes: 16x16, 32x32, 48x48, 256x256

## Creating Assets

### Quick Logo Creation:
1. Download eye icon from free icon site (Flaticon, Icons8, Iconfinder)
2. Convert to PNG 150x150px
3. Save as `assets/logo.png`

### For Development:
If logo.png is missing, the app will hide the logo element and log a warning in console.
